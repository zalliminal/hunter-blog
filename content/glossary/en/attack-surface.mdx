## What is an Attack Surface?

In one sentence: Your attack surface is everything about your system that an attacker could potentially touch or exploit.

The attack surface includes all entry points where an attacker could try to gain access — open ports, exposed APIs, web interfaces, user input fields, network services, cloud storage buckets, employee emails (for phishing), physical access points, and third-party integrations. Every component, feature, or connection adds to the surface area.

Reducing the attack surface is a fundamental security principle: disable unused services, close unnecessary ports, limit API exposure, and follow least-privilege access.
