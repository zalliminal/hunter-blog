## What is a Webshell / Backdoor?

In one sentence: A webshell is a hidden script on a server that lets an attacker access it anytime — like a secret backdoor into a building.

A webshell is a malicious script (PHP, ASP, JSP, etc.) uploaded to a web server that provides persistent remote access. It acts as a backdoor, allowing attackers to execute commands, browse files, steal data, or pivot to other systems. Backdoors can also be planted in firmware, software binaries, or container images.

Webshells are hard to detect because they blend in with legitimate files. They are a common persistence mechanism in web application compromises.
