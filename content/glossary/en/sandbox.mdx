## What is a Sandbox?

In one sentence: A sandbox is a safe, isolated playground where suspicious code can run without harming the real system.

A sandbox is a security mechanism that creates a restricted environment for running untrusted programs. It limits what the program can access — files, network, system calls — so even if the code is malicious, it cannot damage the host system or access sensitive data.

Sandboxes are used everywhere: web browsers use them to safely run JavaScript, mobile apps run in sandboxes, and security analysts use them to analyze malware. Cloud providers also use sandboxing to isolate customer workloads.
