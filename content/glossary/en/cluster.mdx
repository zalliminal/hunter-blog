## What is a Cluster?

In one sentence: A cluster is a team of computers working together like one powerful machine.

A cluster is a group of multiple servers (nodes) connected to work as a single system. Clusters provide high availability (if one node fails, others take over), load balancing (distributing work across nodes), and scalability (adding more nodes as needed).

Clusters are fundamental to cloud computing, Kubernetes, databases, and large-scale web applications. Common examples include Kubernetes clusters, database clusters, and compute clusters.
