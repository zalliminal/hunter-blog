## What is a Sandbox Escape?

In one sentence: Sandbox escape is when code breaks out of its safe, restricted cage and reaches the real operating system.

A sandbox escape is a vulnerability or technique that allows code running in an isolated environment (sandbox) to break out and access the host system. This is critically dangerous because sandboxes are designed to contain malicious code — an escape means the attacker gains full access to the underlying system.

Sandbox escapes have been found in browsers, container runtimes, virtual machines, PDF readers, and JavaScript engines. They are among the most severe vulnerabilities because they bypass the primary isolation mechanism.
