## What is IDOR?

In one sentence: IDOR is changing an ID number in a URL to see someone else's private data.

Insecure Direct Object Reference (IDOR) is an access control vulnerability where an attacker can access data by modifying a reference to an object, like changing `user_id=123` to `user_id=124` in a URL or API request. If the server doesn't verify the user owns that object, the attacker sees another user's data.

IDOR is extremely common in web applications and is a favorite finding for bug bounty hunters. It highlights why access control must be enforced server-side, not just by hiding links.
