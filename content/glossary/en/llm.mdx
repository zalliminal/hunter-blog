## What is an LLM?

In one sentence: An LLM is an AI that has read so much text it can generate human-like responses.

Large Language Models (LLMs) are neural networks trained on massive text datasets — books, articles, code, and the web. They learn patterns in language and can perform tasks like translation, summarization, question answering, code generation, and creative writing.

Examples include GPT-4, Claude, Gemini, Llama, and Mistral. LLMs are the foundation of modern AI applications like chatbots, coding assistants, and content generation tools.
