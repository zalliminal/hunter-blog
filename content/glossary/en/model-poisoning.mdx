## What is Model Poisoning?

In one sentence: Model poisoning is intentionally contaminating an AI's training data so it learns bad behavior.

Model poisoning is a supply-chain attack on AI systems where an attacker corrupts the training data, weights, or fine-tuning datasets. The poisoned model appears normal during testing but behaves maliciously in specific situations — a backdoor triggered by a particular input pattern.

This is especially dangerous with open-weight models and public datasets, where attackers can contribute poisoned data that gets incorporated into widely-distributed models. It's one of the most critical AI security threats.
