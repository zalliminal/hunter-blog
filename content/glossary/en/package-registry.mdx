## What is a Package Registry?

In one sentence: A package registry is like an app store for code — a place where developers publish and download reusable software packages.

Package registries host software packages that developers can install as dependencies. Examples include npm (JavaScript/Node.js), PyPI (Python), Maven Central (Java), RubyGems (Ruby), and Docker Hub (container images). They are essential to modern software development but also a popular supply chain attack vector.

Attackers publish malicious packages with names similar to popular ones (typosquatting) or compromise legitimate packages to distribute malware.
