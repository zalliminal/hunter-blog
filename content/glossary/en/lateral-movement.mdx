## What is Lateral Movement?

In one sentence: After breaking into one computer, the attacker hops to others inside the same network.

Lateral movement is the phase of a cyberattack where an attacker, having gained access to one system, uses it as a foothold to reach other systems within the same network. Techniques include exploiting trust relationships, stealing credentials, using remote admin tools, or abusing network shares.

This is how a single compromised workstation can lead to a full network takeover. Detecting lateral movement is a key capability of SOC teams and EDR systems.
