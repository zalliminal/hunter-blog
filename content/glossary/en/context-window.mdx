## What is a Context Window?

In one sentence: A context window is how many words/tokens an AI model can see at one time — its short-term memory.

The context window is a fundamental limitation of LLMs. It determines how much text the model can consider when generating a response. If a conversation is longer than the context window, the model "forgets" earlier parts. Context windows range from a few thousand tokens (early GPT models) to over a million tokens (Gemini, Claude).

A larger context window allows the model to handle long documents, extended conversations, or large code files. However, larger windows require more computational resources.
