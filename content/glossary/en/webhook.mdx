## What is a Webhook?

In one sentence: A webhook is an automated notification — Service A calls Service B's URL when something happens.

Webhooks are user-defined HTTP callbacks triggered by specific events. When the event occurs, the source service makes an HTTP request to the configured URL with event data. Unlike APIs where you poll for updates, webhooks push data to you in real-time.

Common uses include GitHub notifying CI/CD tools about new commits, payment processors notifying merchants about transactions, and messaging apps receiving automated alerts.
