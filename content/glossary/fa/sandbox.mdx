## <span dir="ltr">Sandbox</span> چیه؟

خلاصه در یه جمله: یه محیط بازی امن و ایزوله که کدهای مشکوک می‌تونن بدون آسیب زدن به سیستم واقعی اجرا بشن.

<span dir="ltr">Sandbox</span> یه مکانیسم امنیتی‌ست که یه محیط محدود برای اجرای برنامه‌های ناشناس ایجاد می‌کنه. این محیط محدود می‌کنه که برنامه به چه چیزهایی دسترسی داشته باشه — فایل‌ها، شبکه، فراخوانی‌های سیستمی — بنابراین حتی اگه کد مخرب باشه، نمی‌تونه به سیستم اصلی آسیب بزنه یا به داده‌های حساس دسترسی پیدا کنه.

<span dir="ltr">Sandbox</span>ها همه جا استفاده می‌شن: مرورگرهای وب ازشون برای اجرای امن <span dir="ltr">JavaScript</span> استفاده می‌کنن، برنامه‌های موبایل توی <span dir="ltr">Sandbox</span> اجرا می‌شن و تحلیلگران امنیتی ازشون برای تحلیل بدافزار استفاده می‌کنن. ارائه‌دهندگان ابری هم برای ایزوله کردن بارکاری مشتری‌ها از <span dir="ltr">Sandbox</span> استفاده می‌کنن.
